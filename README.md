# note分析キット（無料）

noteの数字（スキ・コメント・フォロワー・PV）を**毎朝自動で記録**して、スマホでも見やすい画面にまとめる無料ツールです。
パソコンが苦手な人でも、**4つのステップ**で使い始められます（目安：はじめてなら10分くらい）。

> **自動でスキ・コメント・フォロー・投稿はしません。** 数字を集めて、見やすくするだけです。

---

## できること
- 毎日のPV・スキ・フォロワーの変化をグラフで見る
- 伸びている記事、「読まれているのにスキが少ない記事」「隠れた名作」を見つける
- よくスキ・コメントしてくれる人のランキング、「最近来なくなった人」「常連になりかけの人」のお知らせ
- 今週やるとよいこと（「次の一手」カード）が自動で出る
- 目標にしている人（最大5人）との比較
- （やりたい人だけ）AIが返信やお礼の下書き・次の記事案を作る

## 用意するもの
| もの | 説明 |
|---|---|
| Googleアカウント | Gmail を使っていれば、もう持っています |
| GitHubアカウント（無料） | 毎朝の自動記録を動かす場所です。[GitHub](https://github.com/signup) で無料で作れます（メールアドレスだけでOK） |
| パソコン | 最初の設定だけパソコンを使います。そのあとはスマホで見られます |

お金は一切かかりません。

## 言葉の説明（知らなくても大丈夫）
| 言葉 | ひとことで言うと |
|---|---|
| スプレッドシート | Google の「表計算ノート」。Excel のようなもので、ここに毎日の数字がたまります |
| GitHub（ギットハブ） | 毎朝決まった時間に、noteの数字を取りに行ってくれる「自動のお手伝いさん」を置いておく場所 |
| デプロイ（公開） | スプレッドシートの中身を、スマホで見られる「アプリの画面」にするボタン |
| 合言葉（シークレット） | GitHub のお手伝いさんが、あなたのシートにだけデータを届けるためのパスワード |
| APIキー | AI（Gemini など）を使うための合言葉。**AIを使わないなら不要です** |

## はじめかた（4ステップ）

### ステップ① シートをコピーする
1. [シートのコピーを作る](https://docs.google.com/spreadsheets/d/1cq0Yzy0YjAeg8ucs8TyU-K-PFj0WifnLESKal599-Qc/copy) を開いて、青い **「コピーを作成」** を押します。
2. 自分用のシートが開きます。中身は空っぽで、プログラムだけが入っています。

### ステップ② 「▶ はじめる」を押して、質問に答える
1. 上のメニューの **「note分析」→「▶ はじめる（かんたん設定）」** を押します（「note分析」が見えないときは、ページを再読み込みして少し待ちます）。
2. はじめての1回だけ、Google の確認画面が出ます。
   - 「認証が必要です」→ **OK**
   - 「このアプリは Google で確認されていません」→ 左下の **詳細** →「**note分析キット（安全ではないページ）に移動**」
   - 「note分析キット にログイン」→ 自分のメールか確かめて **次へ**
   - 許可の一覧が出たら、いちばん上の **「すべて選択」にチェック** → **次へ**（「続行」と出たらそれを押す）
   - ※ チェックを付け忘れると動きません。そのときはもう一度「▶ はじめる」を押せば、また同じ画面が出ます
   - ※ 「確認されていません」「安全ではない」と出るのは、Google の審査を受けていない手作りのプログラムだからです。画面に出るメールアドレスは **あなた自身** です（コピーした時点で、作った人＝あなたになります）。**ドライブ全体を見る・消す許可はありません**（下の「許可の中身」参照）
3. 質問が3つ出ます。
   - **自分の note のURL**（note で自分のページを開いたときの、上のアドレス）を貼る
   - **比べたい人の note のURL**（いなければ空のまま OK）
   - 注意を読んで **はい**
4. 「はじめに」タブに、やることのチェックリストが出ます。

### ステップ③ ダッシュボードを公開する（1回だけ）
1. メニューの **「拡張機能」→「Apps Script」** を押すと、プログラムの画面が開きます。
2. 右上の青い **「デプロイ」→「新しいデプロイ」**。
3. 「種類の選択」の歯車 ⚙ →「**ウェブアプリ**」。（すでに「ウェブアプリ」と出ていれば、そのままで OK。**もう一度押すと選択が外れる**ので注意）
4. 次のように選びます。
   - 説明：`はじめての公開`（なんでもOK）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（「Google アカウントを持つ全員」ではありません）
5. **「デプロイ」** を押すと、「ウェブアプリ」の URL（`https://script.google.com/macros/s/…/exec`）が出ます。
6. **その URL を押して、1回開いてください。** 自分のダッシュボードが開けば公開完了です。シートの「はじめに」タブの③が「✅ できた」に変わります。
   - **このURLがあなたのダッシュボードです。** スマホで開いてブックマーク（ホーム画面に追加）しておきましょう。
   - 「全員」にしても、**あなた以外が開くと「作った本人だけが使えます」と出て、中身は見えません。**（GitHub のお手伝いさんがデータを届けられるように「全員」にしています）
   - ③が「まだ」のままなら：URL を開いていないか、アクセスが「全員」になっていない可能性があります。「デプロイ → デプロイを管理」で確かめてください。

### ステップ④ GitHub につなぐ
1. シートに戻って、メニュー **「note分析」→「GitHub に登録する2つを表示」**。URL と合言葉が出ます（この画面は何度でも出せます）。
2. このページ（GitHub）の右上の緑のボタン **「Use this template」→「Create a new repository」**（＝自分用にコピー）。
   - Repository name（名前）：`my-note-analytics` など好きな名前
   - **Private（非公開）** を選ぶ ← 大事
   - **Create repository** を押す
3. できた自分用のページで、上の **Settings（設定）** → 左の **Secrets and variables** → **Actions** → 緑の **New repository secret**。
   - Name に `NA_RECEIVER_URL`、Secret に URL を貼って **Add secret**
   - もう一度 **New repository secret** → Name に `NA_RECEIVER_SECRET`、Secret に合言葉を貼って **Add secret**
   - （シートの画面の「名前をコピー」「中身をコピー」ボタンを使うと楽です）
4. 上の **Actions** →（緑のボタンが出たら）**I understand my workflows, go ahead and enable them**（＝動かしてOK）。
5. 左の **note-fetch** → 右の **Run workflow** → 緑の **Run workflow**。
6. 5〜10分ほど待つと、シートの「はじめに」タブが **🎉 準備完了！** になります。
   以降は**毎朝5時ごろ、自動で記録**されます（GitHub が混んでいると少し遅れます）。

おつかれさまでした！ ダッシュボードのURLをスマホで開いてみてください。

## もっと便利に（やりたい人だけ）

### AIに返信の下書きや記事案を作ってもらう
- 「設定」タブの **AIの種類** で選びます。**Gemini（ジェミニ）なら無料**で使えます。ChatGPT・Claude は使った分だけ有料です。
- [Google AI Studio](https://aistudio.google.com/) を開いて「Get API key（キーを作る）」→ 出てきたキーをコピー。
- シートのメニュー **「note分析」→「AIのAPIキーを登録」** に貼る → **「AIの接続テスト」** で確認。
- 返信の下書きは、あなたが note で書いた過去の返信をお手本に、口調をまねします。「設定」の **返信の口調**・**自分らしさメモ** で好みに寄せられます。
- 下書きは**自動で投稿されません**。読んで、自分で貼って投稿してください。

### PV（ページビュー）も自動で記録する
PVは note にログインした本人しか見られないため、自分のログイン情報（Cookie＝ログインの通行証）を GitHub に預ける必要があります。
1. パソコンの Chrome で note にログイン → キーボードの **F12** → 上の **Application** → 左の **Cookies → https://note.com** → `_note_session_v5` の **Value** をコピー。
2. GitHub の Secrets に、Name `NOTE_SESSION` で登録（ステップ④-3 と同じ場所）。
3. シートの「設定」タブで **PVの自動取得（自分のCookie）** を **はい** に。
- 不安な人はやらなくて大丈夫です。PVは note の画面からコピーして「PV貼り付け」タブに貼る方法もあります。

## 安全について
### 許可の中身
| 許可 | 何に使うか |
|---|---|
| 「Google スプレッドシートのすべてのスプレッドシートの参照、編集、作成、削除」 | 数字を記録・分析する。画面の言葉は広いですが、**実際に開くのはこのシートだけ**です（スマホ用画面からシートを開くのに、この種類の許可が必要なため） |
| 「外部サービスへの接続」 | note・AI・GitHub とやりとりする |
| 「自分がいないときにこのアプリケーションを実行できるようにします」 | 毎朝の分析・AI週報を自動で動かす |
| 「Google アプリケーション内のプロンプトとサイドバーで、サードパーティのウェブコンテンツを表示、実行します」 | 「▶ はじめる」の質問画面やダッシュボードを表示する |
| メールアドレス | ダッシュボードを本人だけに見せる |

メールを送る許可は求めません（v1.6.1 から外しました）。

**Googleドライブ全体の表示・編集・削除の許可は求めません。** もしそう表示されたら、それはこのツールではないので止めてください。

### 守っていること
- データは**あなたの Google と GitHub の中だけ**。作者（配布元）には何も届きません。
- note へのアクセスは**1日1回・3秒以上あけて**控えめに。note がエラーを返したら、その場で止まります。
- 自動でスキ・コメント・フォロー・投稿をする機能はありません。
- 「スキ・コメントしてくれた人」は、note で公開されている名前とIDだけを、自分の記事の分だけ記録します。コメントの本文は保存しません。
- 合言葉・Cookie・APIキーは、あなたのアカウントの中の鍵付きの場所にだけ保存され、シートには書かれません。

### お願い
- GitHub の自分用コピーは **必ず Private（非公開）** に。人を招待しないでください。
- URL・合言葉・Cookie・APIキーは、人に見せたり SNS やチャットに貼ったりしないでください。
- note が公式に公開している仕組みではないため、note の変更で取れなくなることがあります。

## うまくいかないとき
| こんなとき | こうする |
|---|---|
| メニューに「note分析」が出ない | ページを再読み込みして10秒ほど待つ |
| 「はじめに」の ④ がずっと「まだ」 | GitHub の Actions で note-fetch が赤くなっていないか見る。赤いときは Secrets の名前（`NA_RECEIVER_URL`・`NA_RECEIVER_SECRET`）が1文字も違わないか確認 |
| ダッシュボードが「作った本人だけが使えます」になる | シートと同じ Google アカウントでログインしているか確認（スマホのブラウザも） |
| 合言葉をなくした | メニュー「GitHub に登録する2つを表示」でいつでも見られます |

## やめるとき
1. GitHub：自分用コピーの **Settings** → いちばん下の **Delete this repository**（または Actions → note-fetch →「…」→ Disable workflow）。
2. シート：メニュー「受け取り用の合言葉を削除」・「AIのAPIキーを削除」・「Cookieを削除」。Apps Script の「デプロイ → デプロイを管理」で **アーカイブ**。
3. シートごと削除してもOKです。
